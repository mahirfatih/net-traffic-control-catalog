# Changelog

All notable changes to this repository are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Two version numbers live here, and they answer different questions. The
catalog's `version` is a **single integer** — it is SemVer's *major* axis alone,
because a data file has no minor or patch: a field added, removed or renamed is
the only thing that can make a reader change code, and that is a breaking
change. It is not a data version; the data changes on every regenerate without
touching it. The release tags (`v0.0.1`) are what move when the data moves, and
`manifest.json`'s `sha256` says whether two files are the same bytes at all.

## [Unreleased]

### Added

- **Folder-per-question docs** — `docs/` is now organised into `overview/`,
  `guides/`, `reference/`, `security/`, `architecture/` and `diagrams/`, each
  with its own README index, and `docs/README.md` is a map from folder to the
  question it answers. The flat files move with `git mv`, so history is kept.
- **Real architecture diagram** — `docs/diagrams/architecture/` is generated by
  `scripts/checks/build-architecture-diagram.mjs` from the outline in
  `docs/architecture/source.json`: four flows (ingest, verify, build, ship),
  offline/online modes, and eleven nodes that are real scripts and files. The
  previous placeholder (traffic signals, Redis, PDF reports) is gone. `--check`
  fails when the committed HTML is stale, and `test/test.sh` runs it as step 8b.

### Changed

- **Documentation paths** — every reference to the old flat locations is updated:
  the build scripts, `check-docs-fresh.mjs`, `test/test.sh`,
  `scripts/sources/harvest.py`, the `scripts/**/README.md` cross-links and the
  root `README.md` / `README.tr.md` / `CONTRIBUTING.md` links. The generated
  `docs/reference/CATALOG.md` and `COVERAGE.md` are regenerated for their new
  depth.

### Fixed

- **`generate.py --check` ignored `generated_unix`** — it rebuilt the seeds and
  compared the result to the committed `catalog.json`, dropping only the
  `generated` stamp. Because `generated_unix` comes from the same `today`, the
  comparison failed on every day after the file was last regenerated, so
  `test/test.sh` went red for no real change. Both stamps are now ignored.

## [v0.0.1] - 2026-10-20

### Added

- **Catalog format v3** — `catalog.json` now includes `format_version`,
  `manifest_version`, `manifest_file`, and `generated_unix` (snake_case) for
  self-verification by consumers. `manifest.json` upgraded to v2 with snake_case
  keys and `generated_unix`.
- **Distribution contract** — `manifest.json` (sha256, byte count, format
  version, totals) enables consumers to verify freshness before downloading the
  full catalog. `docs/reference/INTEGRATION.md` documents the contract.
- **Release workflow** — `.github/workflows/release.yml` with `workflow_dispatch`
  for manual rehearsal runs; `v*` tag pushes publish `catalog.json`,
  `manifest.json`, `catalog.json.sha256` as a GitHub Release.
- **Bump script overhaul** — `scripts/release/bump-version.sh` now updates
  `format_version`, `manifest_version`, `manifest_file`, `generated_unix`
  across generator, validator, schema, and test fixtures; also rebuilds
  `manifest.json`. `manifest_version` is separate from catalog format version.
- **Test hardening** — `test/test.sh` step 10.14 runs the bumper on a throwaway
  copy of the tree on every suite run, asserting every version literal moves,
  manifest follows, and backwards/repeat/zero bumps are refused.
- **Method note** — `docs/analysis/METHOD.md` walks the scikit-learn estimator
  selection chart gate-by-gate with real `matrix-data.json` numbers, includes a
  mermaid flowchart, and documents three deliberate departures from the chart.
- **Project audit** — `docs/security/audit.md` read-only review: category imbalance,
  source concentration, mislabel, backlog, provenance gaps.

### Changed

- **Catalog format version** 1 → 3 (breaking: new required fields).
- **Manifest format version** 1 → 2 (snake_case keys, added `generated_unix`).
- **Badge updates** — `README.md` / `README.tr.md`: format badge v1→v3, CI badge
  removed (workflows simplified), checks badge 27→28.
- **`bump-version.sh`** — manifest now regenerated alongside `catalog.json`;
  `manifest_version` tracked separately; snake_case field patterns added.
- **Versioning model** clarified in `CHANGELOG.md`: single integer = SemVer
  major axis only; release tags (`v0.0.1`) carry data versions; `sha256` for
  byte-level identity.
- **Workflows** — `.github/workflows/release.yml` restored with `workflow_dispatch`
  for manual rehearsal runs (default tag `v0.0.1`); `.github/workflows/ci.yml`
  and `.github/workflows/sweep.yml` removed.

### Fixed

- `bump-version.sh` now updates `manifest.json` (was stale, causing consumer
  checksum mismatch).
- `bump-version.sh` now updates the bare `built.get("version") != 1` comparison
  in `test/test.sh` step 6 (was reporting contradictory `version is 2, expected 2`).

## [Unreleased]

### Added

- **A method note for the classifier audit** (`docs/analysis/METHOD.md`): the
  run walked through scikit-learn's own estimator-selection chart gate by gate,
  with every answer taken from `matrix-data.json` rather than asserted. It
  records where the chart decides — sparse text and 4,563 samples is the linear
  case, and four of the top five heads by balanced accuracy are exactly that —
  and the three places the audit leaves it on purpose: "get more data" is refused
  for the eight classes under twenty examples (priced as 3 folds and a
  `thin_classes` list, not hidden by dropping them), the labels are the object
  under audit rather than ground truth, and the chart has no box for the
  `GroupKFold` owner-leakage split that moves balanced accuracy 0.605 → 0.553.
  Drawn as a mermaid path annotated with the run's own numbers instead of
  copying the upstream chart in.
- **A distribution contract for other applications**
  (`manifest.json`, `docs/reference/INTEGRATION.md`,
  `scripts/release/build-manifest.py`): the catalog stays plain JSON — no gzip —
  and gains the surface around it an integrating app needs. `manifest.json` is a
  kilobyte holding the catalog's SHA-256, byte count, format version and totals,
  so a consumer can learn whether the data changed before pulling the whole file;
  `--check` proves it still describes `catalog.json` and runs as **step 3c** of
  `test/test.sh`. `docs/reference/INTEGRATION.md` states the two addresses (moving `main`
  versus an immutable `v*` tag) and draws the line between what is guaranteed —
  `version`, `services[].key`, the vocabulary — and what moves on every

  the checks, restores the tagged bytes over the rebuild's re-stamped date, and
  publishes a GitHub Release carrying `catalog.json`, `manifest.json` and
  `catalog.json.sha256`. Third-party actions stay commit-pinned and each job has a
  timeout. No asset is compressed.

  guardrails (canary, two rounds, intersection, logged removal). Linked from both

- **Live sweep** (`scripts/analysis/sweep-live.py`): finds catalog hosts that
  still resolve but no longer serve a page — a parked domain, a lapsed site, a
  host the owner moved — the same domain-recycling risk the dead-domain sweep
  covers, one layer further out. It visits every host with a real browser
  ([agent-browser](https://github.com/vercel-labs/agent-browser) driving
  [Lightpanda](https://lightpanda.io)) because a fetch that does not run
  JavaScript sees an empty shell where a modern page lives, and records the
  status, final URL, title and text length it saw. A navigation failure is only
  believed after a canary proves the engine still works, two rounds must agree,
  and the proposal is cross-checked against `evidence/dead-domain-sweep.json`.
  A verdict this network produced but did not trust — `tls-error`, `timeout`,
  `dns-error` (`youtube-nocookie.com` and `jsdelivr.net` land there on a bad
  afternoon) — is reported for review and never proposed unless
  `--include-flaky` says otherwise. By default only a **parked** page is
  proposed, because a 404 or an empty 200 is common on live infrastructure
  (`adnxs.com`, `3dsecure.akbank.com.tr`); `--aggressive` widens the proposal to
  hosts that answered with nothing.
  Its decision table is checked in `test/test.sh` step 10.10; the script needs
  the network and stays out of CI.

  address block, and bounded traceroute. Finds the recycling case the DNS and
  browser sweeps cannot see: a lapsed name re-registered by someone else that
  inherits the previous owner's category. Two rounds must agree; a host is only
  proposed on a strong signal (`gone`, `expired`); unknown and unsupported TLDs

  `StratifiedKFold` can scatter two hosts of the same owner across folds and let
  the model memorise one to score the other. The matrix is re-run under
  `GroupKFold`, every host grouped by its registrable domain (eTLD+1), and both

- **Browser fallback for thin pages** (`scripts/analysis/fetch-pages.py
  --render-thin N`): a JS-heavy page reaches `curl` as a shell with no prose,
  which is why `gaming`, `cdn` and `software` are measured on a fifth to a third

  harness the live sweep uses** (`agent-browser` + Lightpanda) and keeps the

  `test/test.sh` step 10.13 runs it.

- **Hand-read label precision** (`scripts/analysis/precision-sample.py`,

  classifier. finance **98.5%** (95.7–99.5), government **100%** (96.3–100); the

### Fixed

- **`bump-version.sh` had never run end to end, and the first time it did it
  shipped a stale checksum.** `version` has been `1` since the seed commit, so
  both gaps sat latent. It missed `manifest.json`, which mirrors the field as
  `format_version` and carries the catalog's sha256 — its own output therefore
  failed `build-manifest.py --check`, and the committed manifest would have
  advertised the previous release's bytes to consumers. It now re-derives the
  manifest from the new catalog instead of leaving it behind. It also missed
  the bare `built.get("version") != 1` in `test/test.sh` step 6: `test_exp` only
  matched `expected N` and `"version": N,`, so the check kept testing `1`
  against a version-2 file and reported the contradictory `version is 2,
  expected 2`. The `check_exp` pattern, which already existed for the same
  shape in `catalog-core.py`, is now applied to `test.sh` as well. A new step
  10.14 runs the bumper on a throwaway copy of the tracked files on every suite
  run, so it cannot rot silently again: every version literal must move, the
  catalog must be rebuilt, the manifest must follow, and a backwards, repeated
  or zero bump must still be refused.
- **`guven.com.tr` was mislabeled `finance`; it is now `health`.** The host is
  *Güven Hastanesi* — the live sweep reads its final title as "Ana Sayfa | Güven
  Hastanesi", and the model already predicted `health` at 85%. The seed,
  `catalog.json`, `docs/reference/CATALOG.md`, `docs/reference/COVERAGE.md` and the analysis prose
  are updated; the high-confidence error list drops it (69 → 68).
- **The registration sweep would have deleted live hosts, so it now reads a
  `404` before it trusts one.** `rdap.nic.ms` runs an ordinary web server that
  answers *every* lookup — including its own `nic.ms` — with a Tomcat HTML 404,
  not an RDAP `application/rdap+json` body. The tool read that as "not
  registered" and proposed six live Microsoft `.ms` hosts (`aka.ms`, `jwt.ms`,
  `appcenter.ms`, …) for removal, twice, consistently. A `404` now counts as a
  negative only when the endpoint actually speaks RDAP (the RDAP media type, or
  a parseable RDAP error body); anything else falls through to WHOIS and then to
  `unknown`. Two related guards landed with it: `inactive` and `clientHold` are
  **registered-but-not-delegated** and are now a `review` rather than `gone`
  (`investbank.com.ua`), and a host that still resolves in DNS is never `gone`
  whatever the registry says. The offline decision table in `test/test.sh` step
  10.11 covers all three.

- **The audit was not reproducible: `LinearSVC` ran unseeded.** `random_state`
  was `None`, so liblinear shuffled its dual coordinate descent from OS entropy
  and two runs on identical input produced coefficient tables differing around
  the sixth digit — 277 changed lines in a committed artifact, none of them a
  finding, and no way for a reader to tell noise from a change. All four
  `LinearSVC` instantiations now take the same seed; two full runs produce
  byte-identical `matrix-data.json`, verified by diffing them.
- **Nine of the catalog's 27 categories were never measured, and the cause was
  a bug, not their size.** `fetch-pages.py` wrote an empty cache file the first
  time a host returned nothing and never tried again, so a category was dropped
  from the matrix whenever its first fetch attempt failed. `--retry-empty`
  re-fetches those hosts and tries `www.` as well; it recovered 310 hosts
  overall and took the previously unmeasurable categories from 90/168 to 157/168.
  `sports` went from 0 examples to 7, `crash` from 2 to 11, `maps` from 1 to 3.
- **All 27 categories are now in the matrix.** `--min-class` dropped from 20 to
  2 and the fold count adapts to the smallest category, so `maps` with 3
  examples forces a 3-fold matrix instead of being excluded from it. Eight
  categories rest on under 20 examples and are recorded as `thin_classes` so
  their F1 reads as indicative rather than measured. Accuracy falls from 0.902
  to 0.886 and balanced accuracy from 0.672 to 0.595 — the task is harder now
  that infrastructure categories are included, and that is the honest number.
- **The reliability headline was measuring one category and calling it the
  catalog.** `finance` is 53% of the catalog, so accuracy (0.902) and balanced
  accuracy (0.672) differ by 23 points, and only the first was reported.
  `build-matrix.py` now records balanced accuracy, every document quotes it
  beside accuracy, and `check-docs-fresh.mjs` fails if a document drops it —
  the gap is the finding, so a document that quotes accuracy alone is repeating
  the error.
- **The model comparison was not a fair comparison.** LinearSVC and
  LogisticRegression were evaluated with `class_weight="balanced"` while
  MultinomialNB got no reweighting at all, so two models were being judged on a
  2,359-example class and the third was left to guess it. Naive Bayes rejects
  the string `"balanced"` and accepts only an array, so the inverse-frequency
  prior is now computed as sklearn documents it. The effect is the honest one:
  naive Bayes' accuracy fell 0.792 → 0.734 while its macro F1 rose
  0.197 → 0.259 — a model doing no better than the dominant class, shown
  directly instead of inferred.
- **Nine categories were silently unmeasured.** `maps` (2 examples), `music` (6),
  `sports` (7), `crypto` (8), `other` (9), `telecom` (10), `crash` (11),
  `email` (18) and `cdn` (19) fall below the 20-example class floor. The audit
  reported none of it: `cdn` had already left the matrix once with nothing in
  the output to explain it. Dropped classes are now printed, stored as
  `dropped_classes`, and listed in `docs/reference/CATALOG.md`.
- **The documents quoted a sweep duration nobody had measured.** README, SOURCES,
  CONTRIBUTING and `scripts/README.md` all said the dead-domain sweep takes
  "~30 minutes". It takes about ten: 605 s and 583 s for the two real runs.
  Nothing invalidates a guessed duration, so the three-fold error survived until
  somebody read it. `probe-dead.py` now records `elapsed_seconds` in its
  evidence, and `check-docs-fresh.mjs` compares every duration and host-count
  claim a document makes about the sweep against that record, so the number a
  reader plans around is the number the run actually took.
- **`check-overlaps.py` silently discarded the manual override list.** A dead
  `manual = []` line ran after the overrides were loaded from `rules.json`, so
  the "Manual Overrides" section always reported zero — and the report looked
  correct while the override map was populated. It went unnoticed because the
  map was empty at the time it shipped.

### Added (earlier)

- **A source registry, and a gate that enforces it.** `sources.json` records
  every external list with its licence and a verdict; `scripts/sources/sources.py`
  refuses a non-commercial or share-alike source before it is fetched. The
  README already said not to commit NC data — this makes it true without
  somebody having to remember.
- **`harvest.py`** — fetch an allowed source, drop what the catalog already
  covers, apply `rules.json`, and report what is left. It never invents a
  category, never overwrites an existing label, and never writes `other` on
  its own.
- **`merge.py`** — apply harvested categories to the seeds, refusing to
  overrule a label a person already set and refusing any category outside the
  vocabulary.
- **`probe.py`** (optional) — gather evidence from an external categoriser. Sets
  no category; caches everything it learns in `evidence/probes.json`.
- **`rules.json`** — the categories an external list cannot supply, written down
  with a reason each.
- **`build-catalog-docs.py`** and generated [`docs/reference/CATALOG.md`](docs/reference/CATALOG.md).
- **`check-docs-fresh.mjs`** — catches a renamed file, a stale count, a broken
  link, or a licence verdict that contradicts itself.
- **`test/test.sh`** — the whole suite in one command, no dependencies.
- **Documents** — [`docs/reference/SOURCES.md`](docs/reference/SOURCES.md),
  [`docs/guides/NEEDS-REVIEW.md`](docs/guides/NEEDS-REVIEW.md), [`CONTRIBUTING.md`](CONTRIBUTING.md),
  [`SECURITY.md`](SECURITY.md).
- **A host-shape rule in the validator.** `catalog-core.py`'s `host_problems` refuses a
  wildcard (`*.example.com`), a URL, an IDNA label, a trailing dot, a stray
  space or a bad label — because the app matches a listed host *whole* and its
  subdomains by suffix, with no glob and no IDNA decoding. Such a row would sit
  in the catalog and never match anything. `test/test.sh` step 10 proves each
  refusal, so the rule cannot quietly stop working.
- **A service-domain check in `test/test.sh`.** Step 2b fails when a domain in
  `seeds/services.json` has no category of its own and none from an ancestor.
  That is exactly the state the thirteen above were in: grouped under the right
  product, counted as `"other"`. The check has teeth — remove `threads.com` from
  the seeds and it goes red.
